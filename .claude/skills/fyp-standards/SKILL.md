# FYP standards

These rules come from the module's lecture briefings and are what examiners check. Missing
one costs marks even when the system works, so apply them as written.

Read only the file that matches the task:

| Task | File |
|---|---|
| Tables, columns, migrations, ERD, schema table (Ch 4.3) | [schema.md](schema.md) |
| Unit test cases, bug re-tests, UAT (Ch 4.5, 5.3, 5.4) | [testing.md](testing.md) |

## Always-relevant rules

- **Diagrams (Ch 4.2): Option A only.** The IR chose Scrum, so the path is Use Case Diagram →
  Use Case Specifications → Class Diagram → Activity Diagram → Sequence Diagram. Never add
  DFDs, context diagrams or flowcharts; mixing paths is penalised.
- **Wireframes (Ch 4.4):** at least 25 pre-coding screens, 3-5 lines of description each.
- **Screenshots (Ch 5.1):** at least 25 real post-coding screens, 4-5 lines each.
- **IR reuse (Ch 1-3):** reuse is allowed, but examiners reward refined and expanded text over
  copy-paste.
- **Supervisor meetings:** 3 meetings, 2-3 weeks apart, logged on PG Bank right after; the 3
  log screenshots go in the report (5 marks).
- **Cover page year:** 2026 only, no month.
