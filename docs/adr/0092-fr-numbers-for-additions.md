  Canva-style editor, video, the cost guard, and the AI additions in ADR 0085) had no requirement numbers, so Table 33
  and the R13 drafts could not cite them. Supervisor meeting #1 (L36) allows FR changes when they are justified.
- **Decision:** (user, 29 Oct) each addition gets an FR number from FR20 on, or an NFR number where it is
