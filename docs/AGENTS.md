# docs

Index: `README.md`. These files feed the dissertation, so keep them factual: no invented results or measurements.

- **Decisions**: one file per decision in `adr/` named `NNNN-short-title.md` (next number = highest + 1; D1-D83 are in
  `DECISIONS.md`, frozen). Each says context, decision, alternatives, reversibility.
- **Test cases**: `chapter4/4.5_test_cases.md`, one row per TC ID; IDs are unique across the repo (check before adding).
  `chapter4/CHAPTER4.md` is generated by `chapter4/build_chapter.py`; rebuild it instead of editing it.
- **Diagrams**: Mermaid text in `chapter4/diagrams/src/*.md`; the user renders PNGs. Never PlantUML.
- **State**: `HANDOVER.md` (rewritten each session), `PLAN.md` (milestones), `OPEN_QUESTIONS.md` (user-only questions).
- **Evidence**: `testing/` (audits, load runs, UAT); `screenshots/`; `code-snippets/` (Chapter 5 format in the
  `fyp-standards` skill).
