# NotaLah wireframes v3 (Chapter 4.4)

Generated by `build.mjs` from `screens.mjs`; do not edit by hand. 57 screens
(49 desktop at 1440 x 900, 8 mobile at 390 x 844), 17 of them new in v3.

- **The SVG is the deliverable**: `svg/NN_name.svg` is editable vector (every label is a real `<text>`, shapes are
  rect/path, navigation icons are vector groups, no embedded raster images, main regions are named `<g id>` layers).
  Import with File > Import or drag the files onto a Figma page. `svg/ALL_SCREENS.svg` holds every screen on one canvas.
- PNG (secondary): `png/NN_name.png` (2x), rasterised from the same SVG for the report.
- v3 changes for every screen: greyscale lo-fi; avatars are crossed circles, slides, covers and images are crossed
  boxes, non-navigation icons are dropped or become plain text labels; lorem ipsum for descriptive copy; the slide
  position indicator is a row of dots at the bottom of every slide (top progress bars removed); "For You" renamed
  **Feed**, "Contacts only" renamed **Friends only**, editor top bar gains **Share** (R30).
